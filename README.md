# RimbaBelajar

Website PWA offline-first untuk belajar tentang alam.

## File utama
- `index.html` — halaman utama
- `styles.css` — tampilan
- `app.js` — pencarian, filter, statistik, dan detail materi
- `data/content.json` — isi materi
- `manifest.json` — konfigurasi PWA
- `sw.js` — dukungan offline

## Upload ke GitHub Pages
Upload **isi folder `RimbaBelajar_Web_Lengkap`**, bukan file ZIP-nya saja. Pastikan `index.html` berada langsung di root repository.

Setelah itu:
1. Buka **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: **main**
4. Folder: **/(root)**
5. **Save**

Tunggu beberapa saat sampai GitHub Pages memberikan alamat website.
